Proportion plots

A proportion plot is a column's value_counts(): one box per value, widest (most common) first, in alternating blues. Hover a box for its value, share, and count. For a high-cardinality column only the top values get a box; the rest are lumped into a final catch-all box (a blue in between), whose tooltip says how many distinct values it covers. Boxes never shrink below a visible minimum, and the catch-all kicks in early rather than let a long tail of slivers misrepresent it.

Inline, mid-sentence

Like a spark, a tally sits in running text: the user table is almost all unique ids , the plan column is a few repeated levels , and a legacy field has quietly gone almost all-missing — a red flag worth chasing.
